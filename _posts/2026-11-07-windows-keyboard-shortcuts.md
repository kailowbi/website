title: "Windowsのキーボードショートカットを把握する"
---

Windowsのキーボードショートカットを把握しておく。Windows の思想を知る。

- Mac版はこちら: [Macのキーボードショートカットを把握する]({% post_url 2026-08-29-mac-keyboard-shortcuts %})
- `Ctrl + <key>` はアプリ内コマンドを実行する「アクセラレータ」。Mac の `⌘` に相当する「目に見える操作」（普通のショートカット）。
- `Alt + <key>` はメニュー操作を呼び出す「アクセスキー」で、`Alt + F4` のようなOSレベルのウインドウ操作にも使われる。
- `Win + <key>` はOSレベルの操作（ウインドウ管理、設定、検索など）に使われる。
- ファンクションキー（`F1`〜`F12`）は、エクスプローラーや多くのWin32アプリで共通の慣習的な既定動作を持っている。
- Windowsのショートカットは、最初から一貫した設計思想で作られた体系というより、`Alt`・`Ctrl`・`Win`・アプリ独自のショートカットといった異なる時代の仕組みを廃止せずに積み重ねてきた結果。同じ「閉じる」でも `Ctrl + W`（アプリ内）と `Alt + F4`（OSレベル）が並存するのはその表れ。ここではOS共通で使われやすいものを中心にまとめる。

### 🔧 基本操作
| ショートカット | 説明 |
|----------------|------|
| `Ctrl + X` | 選択項目を切り取り |
| `Ctrl + C` | コピー |
| `Ctrl + V` | 貼り付け |
| `Ctrl + Z` | 操作を取り消し |
| `Ctrl + Y` | やり直し |
| `Ctrl + A` | すべて選択 |
| `Ctrl + S` | 保存 |
| `Ctrl + P` | プリント |
| `Ctrl + O` | 開く |
| `Ctrl + N` | 新規書類またはウィンドウを開く |
| `Ctrl + T` | 新しいタブを開く |
| `Ctrl + W` | ウインドウ（タブ）を閉じる |
| `Alt + F4` | ウインドウを閉じる/アプリケーションを終了 |
| `Ctrl + ,` | 環境設定を開く（アプリによる） |

### 🖥️ ウィンドウとアプリの操作
| ショートカット | 説明 |
|----------------|------|
| `Win + D` | デスクトップ表示切替 |
| `Win + M` | すべてのウインドウを最小化 |
| `Win + ↓` | ウインドウを最小化 |
| `Win + ↑` | ウインドウを最大化 |
| `Win + ←` / `→` | ウインドウをスナップ（画面半分に配置） |
| `Alt + Tab` | アプリ切替 |
| `Win + Tab` | タスクビュー |
| `Ctrl + Alt + Tab` | アプリ切替（固定表示） |
| `Alt + Esc` | 開いている順にウインドウ切替 |
| `Ctrl + Shift + Esc` | タスクマネージャーを開く |
| `Win + Ctrl + →` / `←` | 仮想デスクトップ切替 |
| `Win + Ctrl + D` | 仮想デスクトップを新規作成 |

### 🔍 検索とナビゲーション
| ショートカット | 説明 |
|----------------|------|
| `Ctrl + F` | 検索 |
| `F3` または `Ctrl + G` | 次を検索 |
| `Shift + F3` | 前を検索 |
| `Win + S` | 検索（Windows Search） |
| `Win + E` | エクスプローラーを開く |
| `Space`（プレビューウインドウ表示中） | クイックルック相当（エクスプローラーのプレビュー） |

### 🗂️ エクスプローラー操作
| ショートカット | 説明 |
|----------------|------|
| `Ctrl + Shift + N` | 新しいフォルダ作成 |
| `Ctrl + クリック` | 複数選択 |
| `Shift + クリック` | 範囲選択 |
| `Ctrl + ドラッグ` | コピー |
| `Shift + ドラッグ` | 移動 |
| `Alt + Enter` | プロパティを開く |
| `Alt + ↑` | 親フォルダ表示 |
| `Delete` | 選択した項目をゴミ箱に移動 |
| `Shift + Delete` | 完全に削除（ゴミ箱を経由しない） |
| `Ctrl + D` | ファイルを複製（アプリによる） |
| `F2` | 名前の変更 |

`Ctrl + クリック`・`Alt + ↑`・`F2` は同じエクスプローラー内の操作なのに修飾キーがバラバラに見えるが、これは「複数選択のマウス操作」「ブラウザ的な階層移動」「OS共通のファンクションキー」という別々の慣習がひとつの画面に同居しているため。

<details>
<summary>もう少し詳しく</summary>

- `Ctrl + クリック`：エクスプローラー固有ではなく、Windows全体で使う「リストの複数選択」の共通作法
- `Alt + ↑`：ブラウザの「戻る/進む」（`Alt + ←/→`）と同じ系統の、階層をひとつ上がるナビゲーション慣習
- `F2`：Win32の共通コントロールに元から組み込まれたファンクションキー慣習（`F5`更新、`F3`検索と同じ仲間）

</details>

### 🖼️ スクリーンショット
| ショートカット | 説明 |
|----------------|------|
| `Win + Shift + S` | 範囲指定のスクリーンショット（Snipping Tool） |
| `Win + PrtScn` | 全画面のスクリーンショットをファイル保存 |
| `PrtScn` | 全画面のスクリーンショットをクリップボードにコピー |
| `Alt + PrtScn` | アクティブウインドウのスクリーンショットをコピー |
| `Win + Alt + R` | 画面録画開始/終了（Xbox Game Bar） |

### ⚡ システム操作
| ショートカット | 説明 |
|----------------|------|
| `電源ボタン長押し` | スリープまたは強制終了 |
| `Win + X` | クイックリンクメニュー（電源メニュー含む） |
| `Win + L` | 画面ロック |
| `Ctrl + Alt + Delete` | ロック・タスクマネージャー・サインアウト等のメニュー |
| `Alt + F4`（デスクトップで） | シャットダウンメニュー |

### ⌨️ ファンクションキー
| ショートカット | 説明 |
|----------------|------|
| `F1` | ヘルプを表示 |
| `F2` | 選択項目の名前を変更 |
| `F3` | 検索を開く（エクスプローラー/デスクトップ）、ブラウザでは検索バーを開き、再度押すと次を検索 |
| `F4` | エクスプローラーのアドレスバーの履歴を表示 |
| `F5` | 更新（再読み込み） |
| `F6` | ウインドウ内・デスクトップ上の要素を順に切替 |
| `F10` | メニューバーを有効化 |
| `F11` | 全画面表示切替（主にブラウザ） |
| `F12` | OS共通の既定なし。アプリ独自に割り当てられる（例: ブラウザは開発者ツール、Officeは名前を付けて保存） |
| `F13`〜`F24` | 既定の割り当てなし。一部の拡張キーボードにのみ存在し、アプリ独自のショートカットやカスタムマッピング用に使われる |
