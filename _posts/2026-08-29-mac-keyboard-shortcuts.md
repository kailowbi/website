title: "Macのキーボードショートカットを把握する"
---

karabiner-elements でのより良いキーマッピングを求め、Macのキーボードショートカットを把握しておく。Mac の思想を知る。

- Windows版はこちら: [Windowsのキーボードショートカットを把握する](https://qiita.com/kailowbi/items/35af13031f002df47c25)
- cmd + <key>は「目に見える操作」（普通のショートカット）。
- ctrl + <key>は「目に見えない補助操作」や「カスタム用途」に使われる。エディタアプリであれば、cmd は ファイル操作で、ctrl は文字列操作的な。
- 物理Fキーは同じキーが「メディアキー」と「本来のFキー」の2役を兼ねていて、`fn` で切り替える。デフォルトはメディアキー側が優先され、`fn + Fキー`で本来のFキーが呼び出せる（設定で優先を逆にすることも可能）。本来のFキー側もOSレベルの既定はほぼ未割り当て。

### 🔧 基本操作
| ショートカット | 説明 |
|----------------|------|
| `⌘ + X` | 選択項目を切り取り |
| `⌘ + C` | コピー |
| `⌘ + V` | 貼り付け |
| `⌘ + Z` | 操作を取り消し |
| `shift + ⌘ + Z` | やり直し |
| `⌘ + A` | すべて選択 |
| `⌘ + S` | 保存 |
| `⌘ + P` | プリント |
| `⌘ + O` | 開く |
| `⌘ + N` | 新規書類またはウィンドウを開く |
| `⌘ + T` | 新しいタブを開く |
| `⌘ + W` | ウインドウを閉じる |
| `option + ⌘ + W` | すべてのウインドウを閉じる |
| `⌘ + Q` | アプリケーションを終了 |
| `⌘ + ,` | 環境設定を開く |

### 🖥️ ウィンドウとアプリの操作
| ショートカット | 説明 |
|----------------|------|
| `⌘ + H` | 前面アプリを隠す |
| `option + ⌘ + H` | 他のアプリを隠す |
| `⌘ + M` | ウインドウを最小化 |
| `option + ⌘ + M` | 全ウインドウを最小化 |
| `option + ⌘ + Esc` | アプリを強制終了 |
| `⌘ + Tab` | アプリ切替 |
| `` ⌘ + ` `` | 同一アプリのウインドウ切替 |
| `ctrl + ⌘ + F` | フルスクリーン表示切替 |
| `⌘ + Mission Control` または `fn + H` | デスクトップ表示 |
| `ctrl + ↓` | アプリウインドウ表示 |

### 🔍 検索とナビゲーション
| ショートカット | 説明 |
|----------------|------|
| `⌘ + F` | 検索 |
| `⌘ + G` | 次を検索 |
| `shift + ⌘ + G` | 前を検索 |
| `⌘ + スペース` | Spotlight検索 |
| `option + ⌘ + スペース` | Finder内検索 |
| `ctrl + ⌘ + スペース` または `fn + E` | 絵文字・記号ビューア |
| `スペース` | クイックルック |

| `⌘ + ダブルクリック` | 新規タブまたはウインドウで開く |
| `option + ダブルクリック` | 別ウインドウで開いて元を閉じる |
| `option + ドラッグ` | コピー |
| `⌘ + ドラッグ` | 移動 |
| `option + ⌘ + ドラッグ` | エイリアス作成 |
| `⌘ + ウインドウタイトルクリック` | 親フォルダ表示 |

### 🖼️ スクリーンショット

### ⚡ システム操作
| ショートカット | 説明 |
|----------------|------|
| `電源ボタン長押し` | スリープまたは強制終了 |
| `option + ⌘ + 電源` | Macをスリープ |
| `ctrl + shift + 電源` | ディスプレイをスリープ |
| `ctrl + 電源` | 電源メニュー |
| `ctrl + ⌘ + 電源` | 強制再起動 |
| `ctrl + ⌘ + Q` | 画面ロック |
| `shift + ⌘ + Q` | ログアウト（確認あり） |
| `option + shift + ⌘ + Q` | ログアウト（確認なし） |


### ⌨️ ファンクションキー / fnキー関連
| ショートカット | 説明 |
|----------------|------|
| `F1`〜`F10` | 未割り当て |
| `F11` | デスクトップを表示 |
| `F12` | OS共通の既定なし。アプリ独自に割り当てられることもある（例: Chromeは開発者ツール） |
| `fn + A` | Dock表示切替 |
| `fn + C` | コントロールセンター表示 |
| `fn + D` | 音声入力 |
| `fn + N` | 通知センター表示 |
| `fn + shift + A` | Launchpad表示 |
| `fn + fn（二度押し）` | 絵文字・記号ビューア |
| `fn（長押し）` | Siri起動（既定。システム設定 → Siri で変更可能） |
